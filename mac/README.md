# Magic Keys

SwiftUI menu-bar companion app for the K1. Receives key events over vendor HID,
detects tap / double-tap / hold, and runs configured actions.

## Structure

- `MagicKeysCore/` — SwiftPM package: protocol parsing, gesture engine,
  config models/store. Test with `swift test` (no hardware needed).
- `MagicKeys/Sources/` — app target: HIDService (IOKit), GesturePipeline,
  ActionEngine, SwiftUI UI. Project generated by XcodeGen.

## Build

    brew install xcodegen   # once
    xcodegen generate
    xcodebuild -project MagicKeys.xcodeproj -scheme MagicKeys -configuration Debug build

Or open `MagicKeys.xcodeproj` in Xcode after `xcodegen generate`.

## Developing without hardware

DEBUG builds have a "Virtual K1" menu in the menu-bar extra that simulates
taps, double-taps, and holds on each key.

## Permissions

- Vendor HID input: none needed.
- Keystroke actions: Accessibility (prompted on first use).
- Failure notifications: Notifications (prompted on first failure).
